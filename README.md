# Rahul Raj Photography — Official Website

A premium, cinematic photography & films business web platform built with **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**.

## Features Included
- **Original Brand Identity:** Uses the official Rahul Raj Photography camera logo with dark transparent background.
- **Cinematic Theme:** Deep black (`#050505`), dark charcoal (`#111111`), and signature camera red (`#E50914`).
- **Complete Navigation:** Sticky navbar with blur effect, WhatsApp button, Book Your Event button, and mobile hamburger drawer.
- **10-Section Homepage:**
  1. Full-screen Cinematic Hero with action buttons
  2. Introduction & Storytelling philosophy
  3. Photography Services & Categories (13 categories)
  4. Featured Portfolio Projects with cover shots
  5. Cinematic Films with interactive video preview player
  6. Why Choose Us (8 pillars)
  7. Client Testimonials (sample placeholders)
  8. Instagram Showcase (`@rahul_raj_photography_world`)
  9. Final Call to Action
  10. Professional Footer
- **Dedicated Pages:**
  - `/about`: Brand story, approach, and philosophy.
  - `/portfolio`: Interactive category filters and full-screen Lightbox with swipe/arrow navigation.
  - `/services`: In-depth breakdown of wedding, birthday, car delivery, pre-wedding, and corporate services.
  - `/packages`: Category filters with *"Contact for Price"* and custom quote requests.
  - `/films`: Video duration badges, thumbnails, and preview modal player.
  - `/book`: Complete 16-field enquiry form with mobile validation, unique booking reference generator (`RRP-2026-XXXX`), and WhatsApp redirect.
  - `/contact`: Direct WhatsApp, location, phone, email, and enquiry form.
- **Persistent Floating WhatsApp Button:** Instant customer enquiry connection on every page.

## How to Run on Any Computer

### 1. Requirements
- Node.js (v18 or higher)
- Visual Studio Code or any terminal

### 2. Installation
Open the project directory in your terminal and run:
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open **http://localhost:3000** in your browser.

### 4. Run on Mobile Phone (over Wi-Fi)
```bash
npm run dev:mobile
```
Open the network IP shown in the terminal (e.g. `http://192.168.31.153:3000`) on your mobile phone browser.

### 5. Production Build
```bash
npm run build
npm start
```
